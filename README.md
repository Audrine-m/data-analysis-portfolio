# data-analysis-portfolio
# Superstore Sales Performance Analysis
 Project Overview
This project analyzes retail sales data from a Superstore dataset to uncover key revenue drivers, profitability risks, and opportunities for business optimization. Using Python and data analysis techniques, the project explores sales, profit, discounts, and customer segments to generate actionable insights.

# Objectives
- Understand sales and profit performance across categories and regions
- Identify high-performing and underperforming product segments
- Analyze the impact of discounts on profitability
- Provide data-driven business recommendations

# Tools & Technologies
- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- Git & GitHub

# Dataset
The dataset contains retail transaction-level data, including:
- Sales, profit, quantity, and discount
- Product category and sub-category
- Customer segment
- Geographic information (region, state, city)

# Key Insights
- Technology is the strongest revenue and profit-generating category.
- High discount levels are strongly associated with negative profit margins.
- Several sub-categories consistently operate at a loss.
- The Consumer segment contributes the highest overall profit.
- Profitability varies significantly across regions and product types.

# Visualizations
The project includes:
- Sales and profit by category
- Profit distribution by sub-category
- Discount vs profit analysis
- Regional performance comparisons

# Recommendations
- Prioritize high-margin Technology products.
- Re-evaluate discount strategies to reduce loss-making sales.
- Optimize or discontinue consistently unprofitable sub-categories.
- Use profit margin analysis to guide pricing and promotions.

# Next Steps
- Incorporate time-based analysis with richer datasets
- Build an interactive dashboard (Power BI / Tableau)
